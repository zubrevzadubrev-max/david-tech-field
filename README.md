# Давид: Поле технологий

Сайт создал ученик 11А класса **Русинов Давид**.

Учебная игра «Поле чудес» о семи технологиях: искусственный интеллект, дополненная реальность, биометрическая информация, облачные технологии, автоматизированный перевод, голографическое изображение и робототехника.

## Запуск на компьютере

Откройте `index.html` двойным щелчком. Установка программ и сборка не нужны. Фотографии находятся внутри проекта, внешних библиотек и шрифтов нет. Можно также запустить `python -m http.server 8080` в папке проекта и открыть http://localhost:8080.

## Возможности

- Анимированный барабан, сектора баллов, «Банкрот» и «Пропуск».
- Экранная клавиатура и ввод букв с клавиатуры компьютера.
- Семь раундов, пять жизней в каждом, подсказки за баллы.
- Общий счёт, локальный рекорд, три достижения.
- Именной сертификат по завершении всех раундов: в диалоге печати выберите «Сохранить как PDF».
- Адаптивная версия для телефона, управление клавиатурой, уменьшение анимаций по системной настройке.
- Необязательные звуки, локальные фотографии и SVG-иконка.

Рекорд и имя сохраняются только в браузере; ход игры после перезагрузки начинается заново. Сертификат — игровой, учебный, не официальный документ. Карточки ниже игры содержат понятия для изучения перед прохождением.

## Загрузка на GitHub

1. Создайте пустой репозиторий, например `david-tech-field`.
2. Нажмите **Add file → Upload files**. Загрузите содержимое этой папки, сохраняя вложенные каталоги. `index.html` должен лежать в корне репозитория.
3. Откройте **Settings → Pages** и выберите источник **GitHub Actions**. В проекте уже есть `.github/workflows/pages.yml`; убедитесь, что этот скрытый каталог тоже загружен. Затем запустите **Actions → Deploy static site → Run workflow** или внесите изменение в ветку `main`.
4. Альтернатива: в **Settings → Pages** выберите **Deploy from a branch**, ветку `main` и каталог `/ (root)`. Тогда workflow не нужен.

Команды для тех, у кого установлен Git (вместо YOUR_LOGIN укажите имя аккаунта):

```sh
git init
git add .
git commit -m "Create David technology word game"
git branch -M main
git remote add origin https://github.com/YOUR_LOGIN/david-tech-field.git
git push -u origin main
```

## Структура

`index.html` — разметка; `style.css` — оформление и печать; `app.js` — вопросы и игра; `assets/` — фотографии и favicon; `CREDITS.md` — источники; `.github/workflows/pages.yml` — публикация на Pages.

Для изменения вопросов редактируйте массив `rounds` в `app.js`. Без серверной части, сбора биометрических данных, аналитики и регистрации.
