# DAV SPIN — Поле технологий

Сайт создал ученик 11А класса **Русинов Давид**. DAV — от имени David, SPIN — вращение барабана.

## Запуск

Откройте `index.html`. Все фотографии внутри проекта, внешних библиотек нет. Или запустите `python -m http.server 8080` и откройте http://localhost:8080.

## Что нового

- Выбор любой комбинации из семи тем. Каждая выбранная тема даёт один раунд; порядок случайный.
- Соло, против программного бота или вдвоём на одном устройстве.
- Фотоподсказки или только текстовые вопросы.
- Адаптивная игровая зона, крупные кнопки, отдельные счета и жизни.
- Сертификат для каждого участника-человека после всех выбранных раундов.

## Правила

За букву начисляется номинал сектора, умноженный на число её появлений. После каждой попытки ход передаётся следующему игроку. В режиме вдвоём новый игрок подтверждает готовность. У каждого по пять жизней на раунд. Игрок без жизней пропускается.

«Банкрот» обнуляет только баллы текущего игрока за этот раунд. Баллы прошлых раундов сохраняются. «Пропуск» передаёт ход. Правильный ответ целиком даёт 500 баллов; неверный ответ отнимает жизнь и передаёт ход. Подсказка за 150 открывает одну букву и передаёт ход. При завершении раунда баллы всех игроков за открытые буквы сохраняются, даже если понятие не разгадано.

Бот автоматически вращает барабан и выбирает буквы по частотности с элементом случайности. Когда большая часть слова открыта, он иногда угадывает понятие целиком. Бот может ошибаться. Это локальный игровой алгоритм, не внешний ИИ.

После завершения партии выберите участника и распечатайте его сертификат (или сохраните PDF в окне печати). Сертификат учебный, не официальный документ. Рекорд и имя первого игрока хранятся в браузере; текущая партия не сохраняется при перезагрузке. Карточки ниже игры можно использовать для изучения понятий.
